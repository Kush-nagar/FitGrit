# Akira Chatbot - App Knowledge Base

This document contains comprehensive information about the app features that Akira should know about.

## App Overview

This is a comprehensive health and fitness application that helps users track nutrition, fitness activities, and overall wellness.

## Key Features

### 1. Nutrition Tracking

- **Food Scanning**: Users can scan food items using their camera to automatically identify foods and get nutritional information
- **Food Logging**: Manual food entry with detailed nutritional breakdown (calories, protein, carbs, fats)
- **Nutritional Database**: Extensive database of food items with complete nutritional information
- **Meal History**: Users can view their past food logs and track eating patterns
- **Daily Calorie Tracking**: Monitor daily caloric intake against goals

### 2. Recipe Features

- **Recipe Database**: Collection of healthy recipes with nutritional information
- **Recipe Suggestions**: Personalized recipe recommendations based on user preferences
- **Meal Planning**: Users can plan meals and generate shopping lists
- **Recipe Details**: Each recipe includes:
  - Ingredients list
  - Step-by-step instructions
  - Cooking time
  - Nutritional breakdown per serving
  - Difficulty level

### 3. Fitness Tracking

#### Running Analysis

- **GPS Tracking**: Track running routes with real-time GPS
- **Running Metrics**:
  - Distance covered
  - Pace (min/mile or min/km)
  - Duration
  - Elevation changes
  - Calories burned
- **Running History**: View past runs with detailed statistics
- **Progress Tracking**: Monitor improvements over time

#### Pose Analysis for Exercises

- **AI-Powered Form Checking**: Uses TensorFlow Lite and MoveNet model
- **Supported Exercises**:
  - Squats
  - Push-ups
  - Lunges
  - Planks
- **Real-time Feedback**: Provides form corrections during exercises
- **Rep Counting**: Automatically counts repetitions
- **Angle Analysis**: Measures joint angles for proper form

#### Shuttle Run Tracking

- **Presidential Fitness Test Component**
- **Performance Tracking**: Time and performance metrics
- **Historical Data**: View past shuttle run attempts
- **Progress Monitoring**: Track improvements

### 4. Presidential Fitness Test

The app includes features for tracking all Presidential Fitness Test components:

#### Test Components:

1. **Shuttle Run**

   - 30-foot distance, run back and forth
   - Measures agility and speed
   - Tracked with timing

2. **Mile Run/Walk**

   - Cardiovascular endurance test
   - GPS tracking available
   - Time and pace recorded

3. **Sit-ups/Curl-ups**

   - Core strength assessment
   - Rep counter available
   - 60-second timed test

4. **Pull-ups/Push-ups**

   - Upper body strength
   - Pose analysis for form checking
   - Rep counter

5. **V-Sit Reach**

   - Flexibility assessment
   - Measurement tracking

6. **BMI Assessment**
   - Body Mass Index calculation
   - Height and weight tracking

### 5. Wellness & Mental Health

- **Wellness Dashboard**: Overview of overall health metrics
- **Mood Tracking**: Monitor emotional well-being
- **Stress Management**: Resources and tips
- **Sleep Tracking**: Monitor sleep patterns (if integrated)
- **Mindfulness Features**: Guided meditation and breathing exercises

### 6. User Profile & Settings

- **Personal Information**: Age, height, weight, fitness goals
- **Goal Setting**: Set and track fitness and nutrition goals
- **Progress Tracking**: Visual charts and graphs
- **Achievement System**: Badges and milestones
- **Settings Customization**: Personalize app experience

### 7. Integrations

- **Strava Integration**:
  - Sync activities from Strava
  - Auto-authentication for easy connection
  - Import running and cycling data
  - Export workouts to Strava

### 8. Data & Analytics

- **Progress Charts**: Visual representation of progress
- **Statistics Dashboard**: Comprehensive health metrics
- **Historical Data**: Access all past activities and meals
- **Export Options**: Share data and reports
